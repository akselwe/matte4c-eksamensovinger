## Slik er settene laget

- **Eksamensoppgaver** er klippet direkte fra originalene og tatt med bare når hele oppgaven ligger innenfor 4C-pensum. Hvert sett starter med en liste over hva som er ekskludert og hvorfor; `00-oversikt-tatt-med-og-ekskludert.pdf` har hele oversikten for del 2.
- **Egenlagde oppgaver** er brukt der det finnes få eller ingen eksamensoppgaver (f.eks. tensorer, kurver og flater). De er laget på samme nivå som prøveeksamenen og merket som egenlagde i settet. Løsningene er numerisk verifisert, men kan inneholde feil – åpne gjerne en issue hvis du finner noe.
- Polynominterpolasjon og fikspunktiterasjon er utelatt.
